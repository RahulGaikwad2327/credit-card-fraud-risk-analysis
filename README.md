Fraud detection is a critical focus area for the banking and finance sectors. This Power BI project analyzes credit card transactions to uncover fraud patterns, assess risk, and present the results in an interactive dashboard that supports data-driven decisions.

🚀 Project Highlights
🧹 Data Cleaning & Preparation: Prepared transactional data for fraud risk analysis.
🔎 Exploratory Data Analysis (EDA): Identified fraud trends, patterns, and anomalies.
📊 Interactive Dashboard: Visualized fraud metrics with slicers, filters, and drill-downs.
📈 Risk Assessment Metrics: Highlighted high-risk transactions and analyzed fraud probability.
🌍 Real-World Relevance: Shows how financial institutions use BI to detect and combat fraud.
🛠 Getting Started
Clone or fork this repository.
Open the .pbix file with Power BI Desktop.
Load the dataset included in the repository, or connect your own credit card transaction data.
Explore the dashboard using the slicers, filters, and drill-through options.
🧰 Tools Used
Power BI Desktop (Power Query, DAX)
Excel / CSV for source data
