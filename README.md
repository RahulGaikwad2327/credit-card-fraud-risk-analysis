💳 Credit Card Fraud Risk Analysis | Power BI Dashboard

An end-to-end Power BI project that analyzes credit card transactions to uncover fraud patterns, identify high-risk transactions, and present key risk metrics in an interactive dashboard for faster, data-driven decisions.

## 📌 Problem Statement

Fraudulent transactions cause major financial losses and damage customer trust in banking. The goal of this project is to analyze transaction data to:

- Understand **how and where fraud occurs** (by time, amount, category, and location).
- Identify **high-risk segments** that need closer monitoring.
- Give stakeholders a **clear, interactive view** of fraud metrics instead of raw tables.

## ✨ Features

- **Data Cleaning & Preparation** using Power Query (handling missing values, data types, and formatting).
- **Exploratory Data Analysis (EDA)** to detect fraud trends, patterns, and anomalies.
- **DAX Measures** for fraud rate, total fraud amount, and transaction counts.
- **Interactive Visuals** with slicers, filters, and drill-through.
- **Risk Assessment View** highlighting high-risk transactions.

## ▶️ How to Run

1. Clone the repository:
   ```
   git clone https://github.com/RahulGaikwad2327/credit-card-fraud-risk-analysis.git
   ```
2. Open the `.pbix` file in **Power BI Desktop**.
3. If prompted, update the data source path to the dataset in the `data/` folder (Transform data → Data source settings).
4. Click **Refresh** and explore the dashboard using slicers and filters.
